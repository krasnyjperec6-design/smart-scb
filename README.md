# SMART SCB

Учебная система мониторинга устройств сигнализации, централизации и блокировки.

## Что требуется

- Windows 10 или 11
- Python 3.10 или новее

Дополнительные библиотеки устанавливать не нужно.

## Как открыть

1. Скачайте и распакуйте проект.
2. Дважды нажмите `OPEN_SMART_SCB.bat`.
3. Браузер автоматически откроет страницу симуляции.

Если страница не открылась автоматически, перейдите по адресу:

```text
http://127.0.0.1:8080
```

Окно сервера должно оставаться открытым.

Для ручного запуска:

```powershell
py -3 server.py
```

База данных создаётся автоматически в `database/smart_scb.db`.
